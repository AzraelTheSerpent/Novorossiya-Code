# Код Новороссии

Стек: Laravel 10, Inertia, Vue 3, Pinia 3, MapLibre GL 6, Tailwind, Bootstrap 5. Bootstrap подключён как сетка без глобального reset, стили интерфейса отделены от админки. Для простого локального запуска используется SQLite. Зависимости и lock-файлы сохранены и обновлены при добавлении библиотек.

## Быстрый запуск на Windows

1. Распакуйте архив в обычную папку.
2. Запустите `START.cmd`.
3. Откройте http://127.0.0.1:8088.

В готовой Windows-сборке есть PHP 8.3 x64, Composer-зависимости и собранный интерфейс. Node.js для просмотра готовой сборки не требуется. Может понадобиться Microsoft Visual C++ Redistributable 2015–2022 x64, если компьютер не запускает PHP.

Если порт занят, откройте PowerShell в папке проекта и выполните `./START.ps1 -Port 8090`.
Остановка: Ctrl+C в окне сервера.

При первом запуске создаётся новый APP_KEY, применяются миграции и добавляются демоданные, если каталог пуст. Не используйте `migrate:fresh` на базе с нужными данными. Сохраните `.env`: ключ необходим для расшифровки TOTP-секретов.

## Демо-аккаунты

Общий пароль: `DemoPass2026!`.

| Вход | Назначение |
|---|---|
| user@kod.local | Посетитель: отзывы, маршруты, заявки |
| business@kod.local | Владелец демонстрационных объектов |
| moderator@kod.local | Проверка карточек, отзывов и жалоб |
| curator@kod.local | Работа с заявками инвесторов |
| admin@kod.local | Вертикали, модерация, маршруты, заявки |

Для администратора, модератора и куратора после первого входа обязательна настройка TOTP. Введите показанный ключ в приложение-аутентификатор: 6 цифр, SHA1, период 30 секунд. Затем введите код. Секрет шифруется APP_KEY, повторное использование кода запрещено. В новой сессии потребуется новый код.

В новой пользовательской регистрации создаётся роль `user`, без служебных прав. Любой пользователь может предложить собственный объект. Публикация происходит после модерации.

## Что работает

- Новый адаптивный каталог, тёмная и светлая темы, пять мобильных вкладок: Карта, Каталог, Избранное, Маршруты, Ещё.
- Три вертикали и создание дополнительных вертикалей через кабинет администратора. Дополнительные поля карточек задаются в вертикали.
- Карта MapLibre с OpenStreetMap, кликабельными метками, кластерами с количеством точек, геолокацией и линией выбранного маршрута.
- Поиск по названию, адресу, категории и тегам. Нормализация русского текста, частичные совпадения, простые окончания и одна опечатка.
- Фильтры по вертикали, категории, рейтингу, стоимости, формату и текущему времени работы. Сортировка по популярности, рейтингу, названию и расстоянию после разрешения геолокации.
- Карточки объектов с фотографией, адресом, описанием, контактами, часами работы, датой проверки и дополнительными полями. Избранное, поделиться, внешний дорожный маршрут, сообщение о неточности и жалобы на авторские права.
- Локальное избранное и маршруты без входа. Авторизованный пользователь может вручную объединить избранное с сервером.
- «Креативный Донецк», конструктор личной прогулки с перестановкой точек, сохранением и приблизительным временем. Модераторы публикуют маршруты.
- Афиша с датой и типом события.
- Предложение и редактирование собственного объекта, до пяти фотографий за отправку, подтверждение прав, проверка размера и типа файлов. После изменения карточка возвращается на модерацию.
- Отзывы только после входа, собственный отзыв можно обновить повторной отправкой и удалить. Отзыв не публикуется до модерации. Владелец не оценивает свой объект и может отвечать на отзывы. Рейтинг пересчитывается по одобренным отзывам.
- Площадки для инвесторов, отправка заявки, приватный список заявок, статус и ответ куратора.
- Обязательная TOTP-защита служебного кабинета, серверные проверки роли и владельца.
- PWA-манифест, service worker, кнопка сохранения каталога. На устройстве доступны поиск, карточки, избранное и маршруты. Кэш карты ограничен ранее просмотренными тайлами.
- Справочный помощник в разделе «Ещё».

## Офлайн и установка на телефон

Откройте сайт онлайн и нажмите «Скачать каталог»; дождитесь подтверждения. Затем можно отключить сеть и перезагрузить публичную страницу. Кабинет, вход, отзывы и отправка заявок требуют подключения. Данные кабинета и аутентификации не записываются в service worker.

Чтобы установить на телефон, сайт нужно разместить на HTTPS-домене и открыть в поддерживаемом мобильном браузере. Выберите «Установить приложение» или «На экран Домой». Localhost компьютера с телефона недоступен. PWA не является отдельной сборкой APK/IPA.

OpenStreetMap используется без массовой предварительной загрузки. Просмотренные тайлы ограничены 180 элементами. Полный офлайн-пакет региона требует отдельного поставщика карт или собственного тайлового сервера.

## Запуск из исходников

Нужны PHP 8.3+, Composer, Node.js 22, расширения `pdo_sqlite`, `mbstring`, `fileinfo`, `openssl`, `zip`, `curl`.

```powershell
composer install
npm ci
Copy-Item .env.example .env
New-Item database/database.sqlite -ItemType File
php artisan key:generate
php artisan migrate
php artisan db:seed --class=PlatformSeeder
php artisan storage:link
npm run build
php -S 127.0.0.1:8088 -t public server.php
```

Для разработки запускайте `php artisan serve` и `npm run dev` в отдельных терминалах. Демо-сидер разрешён только при APP_ENV=local/testing. Он использует вымышленные карточки, условные координаты, события и площадки. Фотографии иллюстративные. Существующие права TOTP при повторном запуске сидера не сбрасываются.

## Docker

```sh
docker compose up --build
```

Сайт: http://localhost:8088. SQLite, файлы и ключ шифрования сохраняются в томе `kod_storage`. При первом запуске добавляются демоданные. Docker-конфигурация приложена; в этой среде Docker не запускался. Конфигурация предназначена для локальной демонстрации.

Проверены в Chrome каталог, поиск, избранное, маршрут, вход в кабинет и мобильная ширина 390 px. Дополнительные результаты браузерной проверки находятся в `docs/VERIFICATION.md`.

## Что ещё нужно для полного ТЗ

- Полные офлайн-карты региона и отдельные мобильные сборки, если организаторы требуют APK/IPA.
- Морфологический поисковый движок. Текущий поиск использует эвристику, а не полноценный словарь русского языка.
- Фото к отзывам, запись на мероприятия, портфолио с отдельной галереей, отдельные промокампании и полный CRUD событий в новом кабинете. Часть страниц и контроллеров сохранена, но не заменяет доработку этих сценариев.
- Календарь доступности, расчёт дорожного маршрута и времени по дорогам. Внутренняя линия соединяет точки; дорожный маршрут открывается во внешнем сервисе.
- Полная синхронизация изменений между устройствами с разрешением конфликтов. Сейчас избранное объединяется вручную, личные маршруты сохраняются на сервер.
- Помощник работает как справочник FAQ, отдельный чат-бот не реализован.
- Уведомления и контроль SLA модерации до 24 часов. Очередь есть, автоматический контроль срока не реализован.
- Подтверждение владения организацией, расширенная аналитика, проверенные реальные данные и контакты. Сейчас право редактирования основано на авторе карточки и решении модератора.

Список соответствия ТЗ: `docs/REQUIREMENTS.md`. Сценарий защиты: `docs/DEMO.md`. Иллюстрации и лицензии: `ATTRIBUTION.md`.

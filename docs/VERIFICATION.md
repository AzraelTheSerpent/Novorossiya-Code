# Проверка прототипа

Проверено локально на Windows, PHP 8.3.35, Node.js 22, Chrome.

## Автоматические проверки

- `php artisan test`: 43 теста, 142 assertions, все прошли.
- `npm test`: 3 теста, все прошли, включая русскоязычный поиск, часы работы с переходом через полночь и расстояния.
- `npm run build`: успешно. Worker MapLibre 6 собран отдельным файлом. Есть предупреждение о размере модуля карты, оно не блокирует сборку.
- Тесты PHP используют SQLite `:memory:` и не обращаются к рабочей базе.
- `PwaTest`: манифест содержит иконки 192/512 и maskable, ярлыки; публичные страницы подключают `/pwa.js` и `/pwa.css`; service worker содержит офлайн-оболочку и обработку обновления.

## Браузер

- Главная: 8 карточек, карта и три вертикали.
- Запрос «мастерская»: одна подходящая карточка.
- Добавление в избранное и открытие списка: одна сохранённая карточка.
- Открытие «Креативного Донецка»: три точки маршрута.
- Вход business@kod.local: открывается кабинет владельца.
- Мобильная ширина 390 px: горизонтального переполнения нет, навигация из пяти вкладок.
- Метки карты отображаются после отдельной сборки ESM worker MapLibre.
- После «Скачать каталог» отключена сеть и перезагружена главная: каталог открылся, запрос «кофейня» дал одну карточку, добавление в избранное сохранилось локально.
- Остановлен PHP-сервер и перезагружена главная: service worker отдал сохранённую оболочку с каталогом и данными, карта показала только ранее просмотренные тайлы.
- В Chrome service worker активен, кэши `kod-shell-v4`, `kod-pages-v1` и `kod-data-v1` заполнены; установочный баннер отображается при `beforeinstallprompt`.
- Обновление `kod-shell-v3` → `kod-shell-v4` прошло через баннер «Обновить»: новая версия активировалась, страница перезагрузилась, старая оболочка удалена.
- В проверенных сценариях исключений JavaScript не зарегистрировано. Ошибки загрузки ещё не просмотренных тайлов при отключённой сети ожидаемы.

Иллюстрации, координаты и названия объектов демонстрационные. Docker, APK/IPA и работа на физическом телефоне не проверялись. Полная офлайн-карта региона не подготовлена.

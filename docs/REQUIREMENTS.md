# Соответствие презентации

| Требование | Состояние прототипа |
|---|---|
| Общий каталог, карта, сервер | Реализовано |
| Туризм, креативные индустрии, промышленный и гастротуризм | Три вертикали и демонстрационные карточки |
| Новая вертикаль без релиза | Реализовано через администратора |
| Поля по типу объекта из админки | Строковые поля по вертикали, без сложных схем и обязательности |
| Карточки, фото, адрес, координаты, контакты, время, дата проверки | Реализовано; новые фото владельца проходят модерацию вместе с объектом |
| Избранное, поделиться, сообщить об ошибке | Реализовано |
| Кластеры с количеством и геолокация | Реализовано; геолокация требует разрешения браузера |
| Поиск с морфологией и опечатками | Частично: нормализация, частичные совпадения, эвристические окончания и одна опечатка |
| Фильтры и сортировка | Реализовано для сохранённых полей; расстояние вычисляется по прямой |
| Отзывы 1–5 только после входа | Реализовано, включая запрет самооценки владельца |
| Редактирование и удаление своего отзыва | Реализовано: повторная отправка заменяет свой отзыв и возвращает его на модерацию |
| Фото к отзывам | Не реализовано |
| Ответ владельца, жалоба и модерация | Реализовано; жалоба на отзыв содержит его номер в тексте |
| Модерация за 24 часа | Очередь есть, автоматического SLA-контроля нет |
| Маршруты, порядок, время, паузы | Реализованы точки и порядок, длительность и время посещений готового маршрута; в личном маршруте расчёт приблизительный |
| Креативный Донецк | Демонстрационный маршрут с музеем, мастерской и кафе |
| Афиша и фильтры | Реализовано по типу и дате |
| Портфолио, услуги, стажировки | Через дополнительные текстовые поля, без отдельной медиагалереи |
| Подтверждение прав и жалоба | Подтверждение при публикации и очередь жалоб |
| Кабинет владельца | Предложение/редактирование объекта и фото, ответ на отзывы из карточки |
| Инвестор как профиль пользователя | Реализовано без отдельной роли инвестора |
| Куратор одного окна | Заявки, статусы и ответы |
| Модератор и администратор | Новые кабинеты; служебная админка доступна только администратору |
| Двухфакторная защита служебных ролей | TOTP, шифрование секрета, ограничение попыток, запрет повторного кода |
| Локальное хранение без входа | Избранное, настройки, маршруты и сохранённый каталог |
| Офлайн-карты региона | Частично: кэш просмотренных тайлов, полный пакет региона не реализован |
| Мобильное приложение | Адаптивное PWA, отдельные APK/IPA не подготовлены |
| Светлая и тёмная темы | Реализовано |
| Промокоды | Демонстрационное текстовое поле; нет учёта погашения |
| Чат-бот | Справочный FAQ; чат-бот не реализован |
| Аккаунты и синхронизация | Реализованы; избранное объединяется вручную, полноценного разрешения конфликтов нет |
| Реальные данные региона | Данные демонстрационные, требуется проверенное наполнение |
